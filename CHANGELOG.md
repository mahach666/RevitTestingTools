## [0.1.0] - 2026-10-16

Первый выпуск. В нём объединены два проекта, которые раньше жили в отдельных репозиториях: RevitTestHost и RevitUITesting.

### Добавлено

RevitTestHost, тесты внутри Revit:

- Надстройка Revit, которая находит сборки `*Tests.dll` в папке `TestHost\Tests\` и выполняет тесты в процессе Revit.
- Атрибуты `[RevitFact]`, `[RevitTest]`, `[TestModel]` и контекст теста `ITestContext` (документ, транзакции с автоматическим откатом, параметры прогона).
- Модели: файл `.rvt` (открывается один раз и кэшируется), свежий проект `@new`, активный документ `@active`.
- Три способа запуска: кнопка на ленте, консольная утилита `RevitTestHost.Cli` с кодом выхода по числу неуспешных тестов (`failed` и `error`), режим сервера через именованный канал.
- JSON-отчёт, фильтр тестов по шаблонам с `*`, предупреждения обнаружения тестов.
- Протокол режима сервера с командами `ping`, `documents`, `open`, `close`, `run`.
- Сборка надстройки под Revit 2020-2027 (по одной сборке на год), загрузка тестовых сборок в отдельном контексте на .NET 8 и новее, скрипт `tools/live-check.ps1` для живой проверки по годам.
- Revit 2027: надстройка ставится в `%AppData%\Autodesk\Revit\Addins\2027\`, потому что из `%ProgramData%` Revit 2027 манифесты не загружает.
- Revit 2025 и новее: в режиме сервера надстройка создаёт peer UI Automation для элементов WPF и сбрасывает их кэш потомков, иначе кнопки встроенных панелей ленты снаружи не видны.

RevitUITesting, UI-тесты снаружи Revit:

- Ожидания и действия UI Automation без повторов нажатий, различие «элемента нет» и «приложение занято», журнал шагов.
- Запуск и подхват Revit, сеанс на весь прогон, перезапуск, проверка свободной памяти перед стартом.
- Лента (вкладки, кнопки, выпадающие меню, свёрнутые панели; раскладка вкладок Revit 2025 и новее), окна и диалоги Revit с каталогом известных окон и уборкой перед тестом, док-панели.
- Конфигурация из `revit-ui-tests.json`, `revit-ui-tests.local.json` и переменных окружения.
- Артефакты падения: снимок экрана, дерево окон, журнал шагов, журнал Revit.
- Базовый класс `RevitUiTestBase` для NUnit, проверки в модели через RevitTestHost.
- Консольный инспектор дерева UI Automation.
- Снимок публичного API, из которого ничего не должно пропадать.

Выпуск:

- Пакеты NuGet `RevitTestHost.Sdk` и `RevitUITesting` на nuget.org (публикация из `release.yml` через Trusted Publishing).
- Архивы надстройки для Revit 2020-2027 (по одному на год), CLI и инспектор.
- Установщик надстройки `RevitTestHost-Addin-<версия>.msi`: все годы в одном файле, установка для текущего пользователя в `%AppData%\Autodesk\Revit\Addins\<год>\` только для установленных Revit.
- Пакеты содержат XML-документацию, символы (snupkg) и SourceLink.

### Известные ограничения

- Живая проверка выполнена на Revit 2020.2, 2022, 2025.1 и 2027.2 с английским интерфейсом: смоук режима сервера и 18 из 18 контрактных тестов на каждом году. Годы 2021, 2023, 2024 и 2026 собираются (CI), но в живом Revit не запускались, см. [docs/versions.md](docs/versions.md).
- Установщик и сборки не подписаны: Windows SmartScreen и Revit («Security - Unsigned Add-In») могут спросить подтверждение.
- Не реализованы параметризованные тесты (`[RevitTheory]`), фикстуры уровня модели и окно с деревом тестов.
- Список того, что в живом Revit не проверялось, ведётся в [docs/revit-quirks.md](docs/revit-quirks.md).
