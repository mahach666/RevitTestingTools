# Живая проверка на нескольких версиях Revit

Живые прогоны нужны, чтобы заполнить столбец «Проверено вживую» в [таблице версий](versions.md). Их выполняют на устройстве, где установлены нужные версии Revit. Скрипт `tools/live-check.ps1` делает всё по годам и собирает результаты в одном месте.

## Предусловия

- Windows, установленные Revit нужных лет в `C:\Program Files\Autodesk\Revit <год>\` (другая папка задаётся параметром `-AutodeskRoot`).
- .NET SDK 8, 9 и 10 (для Revit 2027 нужен SDK 10).
- Revit не запущен, свободный commit не меньше 5 ГБ (параметр `-MinFreeCommitGb`).
- Интерфейс Revit запускается с ключом `/language ENU`, это делают скрипты и тесты сами.
- Права на запись в `%ProgramData%\Autodesk\Revit\Addins\<год>\`: Debug-сборка копирует туда надстройку и пример. Для 2027 это `%AppData%\Autodesk\Revit\Addins\2027\`, права администратора не нужны.
- Для каждого года Revit хотя бы раз запускался этим пользователем (создан профиль, принята лицензия). При первом запуске после установки Revit может показать диалоги, которых в тестах нет.

## Запуск

Сначала проверьте план без изменений в системе:

```powershell
powershell -ExecutionPolicy Bypass -File tools/live-check.ps1 -DryRun
```

Реальный прогон по установленным годам (или по списку):

```powershell
powershell -ExecutionPolicy Bypass -File tools/live-check.ps1
powershell -ExecutionPolicy Bypass -File tools/live-check.ps1 -RevitVersion 2020,2024
```

Параметры: `-SkipContract` пропускает контрактные тесты, `-MinFreeCommitGb` меняет порог памяти. Год, для которого нет Revit, пропускается с пояснением, остальные годы проверяются дальше.

## Что делает скрипт для каждого года

1. Собирает в Debug и разворачивает надстройку и пример (`-p:RevitVersion=<год>`).
2. Запускает `tools/serve-smoke.ps1`: запуск Revit в режиме сервера, команды `ping`, `open`, `run`, `close`.
3. Запускает контрактные тесты RevitUITesting с `REVIT_UI_REVIT_VERSION=<год>`.

## Результаты

- `artifacts/live/summary.md`: таблица по годам (сборка, смоук, контракт, примечание).
- `artifacts/live/<год>/`: журнал смоука `smoke.log`, результаты `contract-<год>.trx` и копии файлов доказательств в `evidence/`.
- Файлы доказательств также пишутся в `tests/RevitUITesting.Tests/Contract/Evidence/<имя>-<год>.txt`.

## Что вернуть из прогона

Верните `artifacts/live/` целиком и файлы `Evidence/*-<год>.txt` для каждого проверенного года. Тесты, которые не прошли на конкретном году, показывают различия между версиями Revit (идентификаторы, подписи, поведение окон). Это ожидаемый результат проверки, а не повод ослаблять тесты.

## Что подтверждено прогоном 2026-10-16

- Загрузка тестовых сборок в Revit 2025.1 и 2027.2 (`TestLoadContext`): `run` смоука находит и выполняет тест примера.
- Среда выполнения Revit 2027: сборка net10.0-windows загружается и работает.
- Диалог «Security - Unsigned Add-In» в Revit 2025.1 и 2027.2 появлялся после пересборки надстройки, хотя `trustAddins` записал 1 в `HKCU\Software\Autodesk\Revit\Autodesk Revit <год>\CodeSigning\<GUID>`. Его закрыл ответ «Always Load» (`TDM_CLICK_BUTTON` 1001), запуск продолжился.
